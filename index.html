BLOCK VS. INLINE

Block: Ocupa toda a largura disponível, iniciando em uma nova linha. Exemplo: <p> & <h1>.

Inline: Ocupa apenas a largura necessária, permitindo que outros elementos fiquem na mesma linha. Exemplo: <a> & <img>.

SPAN VS. DIV

Span: É um elemento inline usado para aplicar estilos ou scripts a uma parte específica do conteúdo dentro de um elemento. Exemplo: <span>.

Div: É um elemento de bloco usado para agrupar outros elementos e aplicar estilos ou scripts a eles. Exemplo: <div>.

TAGS Únicas

As tags únicas são elementos que não possuem uma tag de fechamento. Elas são usadas para inserir conteúdo ou criar elementos sem a necessidade de um par de tags. Exemplos: <img>, <br>, <hr>.

Regresso as Aulas de Web

O HTML é uma linguagem de marcação usada para estruturar e apresentar conteúdo na web. Ele permite criar páginas web, definir a estrutura do conteúdo, adicionar elementos multimídia, links, formulários e muito mais. O HTML é a base da construção de websites e é interpretado pelos navegadores para exibir o conteúdo de forma visualmente compreensível aos usuários.

O CSS (Cascading Style Sheets) é uma linguagem de estilo usada para definir a aparência e o layout de elementos HTML em uma página web. Ele permite controlar cores, fontes, tamanhos, espaçamento, posicionamento e outros aspectos visuais do conteúdo. O CSS é aplicado aos elementos HTML para criar designs atraentes e consistentes, separando a apresentação do conteúdo.

O JavaScript é uma linguagem de programação usada para adicionar interatividade e comportamento dinâmico às páginas web. Ele permite manipular elementos HTML, responder a eventos do usuário, realizar validações de formulários, criar animações, fazer requisições assíncronas e muito mais. O JavaScript é executado no navegador do usuário e é amplamente utilizado para criar experiências web interativas e responsivas.

Elementos Semânticos

Os elementos semânticos são tags HTML que possuem um significado específico e descrevem o propósito do conteúdo que envolvem. Eles ajudam a estruturar a página de forma mais clara e compreensível, tanto para os desenvolvedores quanto para os mecanismos de busca e leitores de tela. Alguns exemplos de elementos semânticos incluem:

  • <header>: Representa o cabeçalho de uma seção ou página.
  • <nav>: Define uma área de navegação com links para outras páginas ou seções.
  • <main>: Indica o conteúdo principal da página.
  • <article>: Representa um conteúdo independente, como um artigo ou postagem de blog.
  • <section>: Define uma seção temática dentro de um documento.
  • <aside>: Representa conteúdo complementar, como barras laterais ou informações adicionais.
  • <footer>: Indica o rodapé de uma seção ou página.

O uso de elementos semânticos melhora a acessibilidade, a indexação pelos motores de busca e a compreensão geral do conteúdo da página, tornando-a mais estruturada e significativa.
